# Rayman Raving Rabbids Bonus Unlocker
How to use:
Find your save file (it’s in the game folder).
Upload the file to the tool, apply the changes, and replace the original save file.
Important note: the program works correctly on saves with 100% completion of the storyline. In addition, it is strongly recommended to play at least one bonus level before editing.
I tested the functionality only on the Steam version; use other versions at your own risk.
